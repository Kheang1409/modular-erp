# Security Policy

The project is pre-release and does not yet publish supported versions. Do not report vulnerabilities in public issues. Use GitHub private vulnerability reporting when enabled, or contact the repository owner privately.

Include affected version/commit, reproduction steps, impact, and any suggested mitigation. Never include live credentials or customer data. Module assemblies execute trusted server code and are not sandboxed. Rotate any secret accidentally committed or disclosed; deleting it from a later commit is not sufficient.
